# Умный подбор подрядчиков

Проект команды **OZGE** для хакатона **HackAlem AI** (23.09.2026), трек «Креативные индустрии».

> ⚠️ Статус: каркас проекта. README заполняется по ходу работы, финальная версия — к 17:45.

## Какую задачу решаем

На креативном рынке заказчик и подрядчик не могут найти друг друга, потому что **разговаривают на разных языках**:

- **Заказчик не умеет формулировать задачу.** Он приходит с фразой «нужно видео для инстаграма, что-нибудь красивое» — без формата, сроков, объёма и бюджета.
- **Подрядчик получает кривой бриф** и заказчиков не по бюджету. Время уходит на переписку, которая заканчивается ничем.

Приложение берёт свободный запрос заказчика, **само превращает его в нормальный бриф** и подбирает подрядчиков, которые подходят по услуге, городу, бюджету и стилю — с объяснением, почему подходят.

## Что делает приложение

1. Заказчик пишет запрос обычными словами.
2. Приложение собирает из него структурированный бриф и задаёт недостающие вопросы.
3. Подбирает подходящих подрядчиков из базы и объясняет каждый выбор.
4. Отдаёт готовый текст брифа, который можно отправить подрядчику.
