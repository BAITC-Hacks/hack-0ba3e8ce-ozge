## Как работаем

1. **Сначала MVP.** Минимальная версия, которая запускается одной командой. Новые функции — только после того, как MVP работает.
2. **Стек:** Python 3.11 + Streamlit + OpenAI API (модель `gpt-4o-mini`). Без баз данных, без Docker, без фронтенд-фреймворков.
3. **Данные подрядчиков.** Если в ТЗ дана база — работаем только с ней. Если базы нет — генерируем демонстрационную (30–50 вымышленных подрядчиков) и явно пишем в README, что данные выдуманные.
4. **Каждый законченный шаг:** запустить проект → убедиться, что работает → `git add` → `commit` с понятным сообщением на русском → `push`.
5. **Ключи API только в `.env`** (он в `.gitignore`). В репозитории лежит `.env.example` с пустыми переменными. Реальный ключ в git не попадает никогда.
6. **ДЕМО-РЕЖИМ обязателен.** Без ключа приложение полностью работает на заготовленных примерах запросов и ответов. Эксперты должны проверить проект без личных аккаунтов участника.
7. **README.md ведём с первого часа:** что делает проект, какую задачу решает, системные требования, установка, переменные окружения, запуск, как проверить (с примерами), демо-режим, использованные библиотеки и модели.
8. **requirements.txt** — с точными версиями (`==`).
9. **Перед каждым коммитом запускать проект и самому чинить ошибки.** Не говорить «готово», пока запуск не проверен.
10. **Объяснять Акжаркын коротко и простыми словами:** что сделано и как посмотреть результат.

## Требования организаторов, которые нельзя нарушать

- Промежуточный результат в репозитории **каждый час** (проверяют историю коммитов).
- Эксперты запускают проект **сами по README**. Не запустилось — дисквалификация.
- Все сторонние библиотеки, модели и шаблоны перечислены в README.
- Готовый продукт, сделанный до 13:00, приносить нельзя.

## Продуктовый фокус

Решение закрывает две боли креативного рынка:
- **Боль заказчика:** не может сформулировать, что ему нужно → приложение собирает из свободного запроса нормальный бриф.
- **Боль подрядчика:** кривые брифы и заказчики не по бюджету → подрядчик получает структурированный бриф и отсев по бюджету заранее.
